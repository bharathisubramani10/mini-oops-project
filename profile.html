Encapsulation in Grievance Entity

Every field in Complaint is marked with private access modifier. State transitions are protected by validating mutators:

// Private encapsulated fields
private String id;
private PriorityLevel priority;
private ComplaintStatus status;

// Validating Mutator
public void setStatus(ComplaintStatus next) {
  if (!isValidTransition(this.status, next))
    throw new InvalidStatusTransitionException();
  this.status = next;
}
Getters permit read access while setters ensure that an Open ticket cannot be Closed without investigation notes.
